# ltr — Локальный переводчик с TUI-интерфейсом

Локальный переводчик, использующий библиотеки `textual` (для графического интерфейса) и `argospace` (для перевода текста). Позволяет переключаться между языковкими пакетами через встроенный интерфейс.

### Возможности:
1. **Редактирование:** Ввод и просмотр текста в двух колонках
2. **Автоматический перевод:** Перевод при начале ввода (debouncing)
3. **Выбор языка:** Автоматическое определение (ru/en/cyrillic), или ручной выбор
4. **Копирование перевода:** Функция для быстрого копирования результата
5. **Установка языковых пакетов:** Встроенный интерфейс для скачивания и установки новых языков
6. **Буфер обмена:** Поддержка вставки текста из буфера

### Установка на Arch Linux:
```bash
sudo pacman -S --needed python wl-clipboard      # wl-clipboard или xclip — для копирования/вставки
python -m venv ~/.local/share/ltr-venv
~/.local/share/ltr-venv/bin/pip install argostranslate textual
install -Dm755 ltr ~/.local/bin/ltr
sed -i '1s|.*|#!'"$HOME"'/.local/share/ltr-venv/bin/python|' ~/.local/bin/ltr
```

### Запуск:
```bash
ltr                # открыть интерфейс
ltr "Hello world"  # открыть с готовым текстом
```

### Клавиши:
| Клавиша | Действие |
|---------|----------|
| Ctrl+T | Перевести сейчас (обычно перевод идёт сам, пока вы печатаете) |
| F2      | Поменять языки местами |
| F3      | Скопировать перевод |
| F4      | Скачать / управлять языковыми пакетами |
| F5      | Очистить поле ввода |
| F6      | Вставить текст из буфера обмена |
| Ctrl+Q  | Выход |
